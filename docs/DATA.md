## 0. 結論サマリ

- 吉原AOIについて、**PLATEAU（意味）** と **0.5m高解像度DEM（微地形）** は両方とも入手可能。**[実測]**
- **PLATEAU地形モデルは5m格子TIN**、京都府DEMは**0.5m格子** → **解像度差 10倍**。比較の前提は成立する。**[実測]**
- 京都府の**高潮浸水想定区域（水防法指定）は存在しない**。PLATEAUの舞鶴災害リスクモデルも 洪水(fld)・津波(tnm)・土砂(lsld) のみで **高潮(htd) は無い**。
  → 高潮水位は「指定ハザードの読み込み」ではなく**潮位統計を根拠にしたパラメータ H** として扱う。**[実測/既知]**
- 舞鶴の**公開 LAS/LAZ 点群は見つからなかった**。**[実測]** → 点群は別途提供予定。それまでは京都府0.5m DEMを高解像度地形の代替とする。

## 2. 高解像度地形：京都府「数値標高モデル（DEM）」

- カタログ: https://www.geospatial.jp/ckan/dataset/dem05_kyoto **[既知]**
- 提供: 京都府 農林水産部 林務課 **[既知]**
- 計測: 平成31（2019）〜令和5（2023）年の航空レーザ計測 **[既知]**
- 形式: **GeoTIFF, Float32, 0.5 m グリッド, nodata = -9999** **[実測: gdalinfo]**
- CRS: **EPSG:6674**（JGD2011 / 平面直角座標系 第VI系） **[実測]**
  - **[注意/実測]** GeoTIFFキーのCRS定義がEPSGレジストリと完全一致せずGDALが警告を出す。再投影時は `GTIFF_SRS_SOURCE=EPSG` の指定を推奨。
- 高さ: 標高（T.P.）。海面・水面はおおむね 0 付近、水域外周に nodata **[実測]**
- 1タイル = 2000 × 1500 px = **1000 m (E) × 750 m (N)**, 約 12 MB **[実測]**

### タイル命名（国土基本図図郭）の解読 **[実測: 実データのワールドファイルから導出・検証]**

`{系}{行}{列}{d1}{d2}{d3}{d4}` 例 `06LC9444`。

- `06` = 平面直角座標系 第VI系
- 2文字目 = 1/50000 図郭の行（南向き 30 km 刻み, `A`→ X最大）
- 3文字目 = 1/50000 図郭の列（東向き 40 km 刻み）
- 図郭 `06LC` の北西端 = **(E, N) = (-80000, -30000)**、`06MC` の北西端 = (-80000, -60000) **[実測: `06LC0011` の原点が (-80000,-30000)]**
- `d1` = 1/5000 図郭の行 (0-9, 3000 m 刻み)、`d2` = 列 (0-9, 4000 m 刻み)
- `d3` = 1/2500 象限 (2000×1500 m): 1=北西, 2=北東, 3=南西, 4=南東
- `d4` = 1/1000 象限 (1000×750 m): 1=北西, 2=北東, 3=南西, 4=南東

```
E0 = -80000 + d2*4000 + (2000 if d3 in {2,4} else 0) + (1000 if d4 in {2,4} else 0)
N0 = -30000 - d1*3000 - (1500 if d3 in {3,4} else 0) - (750 if d4 in {3,4} else 0)   # 06LC
```
（4タイルで検証済: `9621`,`8641`,`0011`,`9631` すべて一致）

### 吉原AOIに必要なタイル **[実測: 実際にダウンロードして確認]**

AOIが 1/50000 図郭 `06LC` / `06MC` の境界（N = -60000）を**またぐ**点に注意。

| タイル | 収録zip | 範囲 E | 範囲 N | 標高 min/max/mean |
|---|---|---|---|---|
| `06LC9443` | 06LC.zip (3.69 GB) | -62000〜-61000 | -60000〜-59250 | 0 / 50.2 / 1.93 |
| `06LC9444` | 06LC.zip | -61000〜-60000 | -60000〜-59250 | 0.1 / 257.8 / 85.8 |
| `06MC0421` | 06MC.zip (10.70 GB) | -62000〜-61000 | -60750〜-60000 | 0 / **5.80** / **1.17** |
| `06MC0422` | 06MC.zip | -61000〜-60000 | -60750〜-60000 | 0 / 123.2 / 22.1 |

`06MC0421` は最大 5.8 m・平均 1.17 m の**極めて低平な区画**であり、吉原の集落中心を含む。

**zip全体をダウンロードする必要はない**: S3/CKANともHTTP Rangeに対応しており、
zipのcentral directoryを読んで必要メンバーだけ抜き出せる（実装済み: `scripts/fetch_kyoto_dem.py`）。**[実測]**

### 内容の目視検証 **[実測]**

0.5m DEMをカラー段彩で描画した結果:
- 建物は**除去されている**（bare earth）。建物跡地に補間によるゴースト（わずかな平坦パッチ）が残る。
- 路地・道路・水路の護岸線・小段差が明瞭に読み取れる。
- 吉原入江・伊佐津川の水面は 0 付近でフラット。
- 集落部の地盤は概ね **0.5〜3 m T.P.**。

→ 高潮の連結性を左右する微地形（護岸天端、道路の微峰、路地の窪み）が実際に表現されている。

## 3. 点群（LAS/LAZ）

### 探索結果 **[実測]**

G空間情報センターの点群関連データセット（46件）を全件確認。**京都府域のものは1件も無い。**
（神奈川・静岡・東京・埼玉・山梨・北海道・大阪市・広島・山形・能登 等）

- 国土地理院「3次元点群データ」: LAZ (LAS 1.2 PDRF3), 4点/m²以上, 高さ精度約25cm,
  ground/water/other の分類あり、2次メッシュ単位。ただし **受注生産・有償**（日本地図センター, 13,900円/2次メッシュ）。
  京都府の整備範囲は **[未確認]**。 https://www.gsi.go.jp/gazochosa/tengun.html **[既知]**
- 京都府の航空レーザ計測の**原点群は公開されていない**（DEM/DCHM/赤色立体地図というラスタ成果のみ）。**[実測]**

### 方針

**点群は別途提供予定（ユーザ側で準備）。** それまでは京都府0.5m DEMを高解像度地形の代替とする。
提供後に想定する仕様と、確認が必要な項目:

- 形式: LAS / LAZ
- CRS: 平面直角座標系VI系（EPSG:6674）想定。**要確認**（緯度経度 / 楕円体高 / 別系の可能性）
- 高さ: 標高(T.P.) か 楕円体高 か。**楕円体高ならジオイド補正が必須**
- 密度: 目標 4点/m² 以上（0.5m DTM生成の目安）
- classification: `2 = ground` が入っているか。無ければ PDAL `filters.smrf` で地面抽出
- 取得年月日（京都府DEM 2019-2023 との時期差が差分解釈に効く）

## 4. 高潮水位

### 前提 **[実測]**

- **国土数値情報 A49「高潮浸水想定区域」に京都府は含まれない**（千葉・東京・神奈川・愛知・三重・大阪・兵庫・徳島・香川・福岡・大分・宮崎ほか計14府県のみ）。
- PLATEAU舞鶴にも高潮(`htd`)モデルは無い。

→ **指定ハザードとしての高潮浸水想定は舞鶴には存在しない。** 水位は潮位統計を根拠にパラメータ化する。

### 舞鶴 潮位観測所（気象庁, 記号 MZ） **[実測: 気象庁ページの数値]**

| 項目 | 値 |
|---|---|
| 位置 | 北緯 35°29′, 東経 135°23′ |
| MSL − 潮位表基準面 | **19.0 cm** |
| MSL の標高 | **+12.4 cm (T.P.)** |
| **潮位表基準面の標高** | **−6.6 cm (T.P.)** |
| **観測基準面の標高** | **−151.7 cm (T.P.)** |

**基準面が2種類ある点が最大の落とし穴。**

```
潮位表（推算潮位）の値 t_cm → T.P.(m) = t_cm/100 − 0.066
毎時潮位（観測値）の値 o_cm → T.P.(m) = o_cm/100 − 1.517
```

DEMは T.P. 基準なので、**水位Hは必ずT.P.に変換してから比較する。**

### 国土地理院 舞鶴験潮場 **[既知]**

登録番号 2607 / 京都府舞鶴市大字浜字浜2010 / 観測開始 1968年6月 / 電波式 / 取付水準点 一等水準点1362
https://cais.gsi.go.jp/cmdc/center/kenchojo/maizuru/maizuru.html

### 基準となる潮位（`scripts/86_tide_levels.py` で再現可能）

| 基準 | 値 [m T.P.] | 区分 | 根拠 |
|---|---:|---|---|
| 平均水面 (MSL) | **+0.124** | **[実測]** | 気象庁の推算潮位表（毎時値, 2026年）から計算。気象庁公表値と一致 |
| 朔望平均満潮位（近似） | **+0.439** | **[実測/近似]** | 同上。日最高潮位の上位24日の平均。厳密な定義ではない |
| 天文潮の最高 | **+0.484** | **[実測]** | 同上。気象擾乱を含まない |
| **既往最高潮位** | **+0.93** | **[既知]** | **1998-09-22 台風7号**。京都府「丹後沿岸海岸保全基本計画」（原典: 気象庁）<br>https://www.pref.kyoto.jp/shingikai/kaigan-01/documents/shiryo4.pdf |

**検算**: 推算潮位表から求めた年平均が、気象庁公表の平均水面 T.P.+0.124 m と
小数第3位まで一致した。基準面の換算（潮位表基準面 = T.P.−0.066 m）と
書式の読み方が正しいことの裏付けになっている。

既往最高潮位 +0.93 m は天文潮最高 +0.484 m より **0.45 m 高い**。
この差が高潮偏差（気象擾乱）にあたる。

### この水位で解析結果がどうなるか **[実測]**

| 基準水位 | H [m T.P.] | 判定が変わる地物 | PLATEAU で浸水 | 0.5m で浸水 |
|---|---:|---:|---:|---:|
| MSL | 0.124 | 0 | 0 | 0 |
| 朔望平均満潮位（近似） | 0.439 | 14 | 2 | 16 |
| 天文潮最高 | 0.484 | 26 | 3 | 27 |
| **既往最高潮位** | **0.930** | **95** | **406** | **405** |

（信頼可能な 905 地物中。`data/out/tide_levels.json`）

**既往最高潮位では、浸水する地物の総数は 406 と 405 でほぼ同じなのに、
そのうち 95 件（10.5%）は別の地物である。** 総数だけ見ていると差が無いように見える。

### まだ未確認のもの

- **[未確認]** 京都府「丹後沿岸海岸保全基本計画」における**設計高潮位・計画高潮位**の数値。
  同計画には計画天端高の**算定式**（`計画天端高 = 計画高潮位 + うちあげ高 + 余裕高`）は
  載っているが、舞鶴の個別海岸ごとの計画高潮位そのものは本文から取れなかった。
- **[未確認]** 吉原入江の**護岸天端高**（これが分かれば「越流するH」を直接特定できる）

### 水位スライダの設定

T.P. **0.0 〜 +3.0 m** を掃引し、上表の4つを目盛りとスナップボタンで置く。
高潮浸水想定区域の指定が無い以上、H は依然としてパラメータだが、
**根拠のある目盛りが入ったので「どの水位が現実的か」は判断できる。**
