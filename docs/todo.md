## やると決めていないもの（判断が要る）

- **判定が変わる地物の一覧表示 / 書き出し。** いまは地図をクリックして 1 件ずつしか見られない。
  庁内で使うなら一覧や CSV が要りそうだが、`docs/design.md` の「やらないこと」に
  **「過度な UI 作り込み、印刷レイアウト」**を挙げている。要件を確認してから決める。
- **時系列（潮位の時間変化）。** 同上「やらないこと」。静水位モデルなので、
  出すなら「時間発展ではなくパラメータ掃引」であることを画面で明示する必要がある。
- **`diff_res`（解像度だけ）を `判定差` ボタンに出すか。** 焼いてあるが載せていない。
  `highres` に割り当てると「0.5m の判定差」の意味が合計 12.7 % から解像度だけの
  3.4 % に変わり、`README.md` と `docs/results.md` の見出しと食い違う。
  **発表でどちらを主役にするか**で決まる。
- **点群のノイズ点。** SLAM は空に散る点を残していて、実測 RGB で塗ると
  水色の粒として目立つ（彩度を 1.15 に抑えて緩和はしてある）。
  高さでクリップするか、配信前の間引きで落とすかは**データ側の判断**。
- **`fast4g` で建物 2 枚と点 56,000 点のどちらを採るか。** 点群の予算を
  1 MB から 0.5 MB に下げると 12 秒窓の建物が 20/22 -> 22/22 になるが、
  常駐点数が 68,622 -> 12,612 に落ちる（`docs/web_results.md`）。
  いまは点群側を採っている（残り 2 枚は 12 秒直後に届く）。**用途で決まる話**なので、
  庁内での使われ方を確認してから決める。
