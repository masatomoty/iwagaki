# 1. 背景と目的

**このプロジェクトの目的は、同じ潮位でも地形データの違いによって、どの建物・どの道路の
浸水判定が変わるかを明らかにすることである。**

::: tip このレポートの要点（結論の先取り）
- 浸水**面積の総量**は 5m 地形でも大きく外さない。外れるのは**個別の建物・道路の場所**で、
  そこは地形データによって変わる。
- **数 cm の潮位差で浸水判定が大きく変わる場所がある**。実測の被害記録もそれを示している。
- 精緻化の優先は「全域の高解像度化」より「越流点・護岸天端・排水吐口の cm 級測量」。
:::

## 1.1 答えたい問い

舞鶴市（都市計画課）から 2026 年 8 月に示された課題を起点とする。要望を問いに整理すると：

1. **5m 地形と 0.5m 地形で、浸水する場所はどの程度変わるか**（→ [4.2](./pages/results)）
2. **潮位が数 cm 変わると、建物・道路の判定はどう変わるか**（→ [4.1](./pages/results)）
3. **将来の高い潮位や排水路を考慮すると、どの地域が重要か**（→ [4.3](./pages/results)・[4.4](./pages/results)）
4. **任意の潮位・時刻歴の潮位で海面を可視化し、点群とも重ねられるか**（→ [2 章](./pages/viewer)）

背景として、舞鶴市には既往最高潮位 T.P.+0.93 m（1998 年 9 月・台風 7 号）の記録があり、
令和 8 年 2 月には京都府により高潮浸水想定区域（水防法第 14 条の 3）に指定されている。

::: warning 「海面上昇の予測」ではなく「水位別の影響分析」
このプロジェクトは、**将来の海面上昇量そのものを予測するのではなく、複数の検討水位を
入力して浸水範囲の変化を見る**ものである。潮位は入力パラメータであって予測値ではない。
:::

## 1.2 対象地域

主な解析対象は **吉原・西舞鶴・東舞鶴の 3 地域**であり、**舞鶴市全域を評価したものではない**。

| 範囲 | 面積 | 地形データ | 点群 |
|---|---:|---|---|
| **吉原**（主対象） | 100 ha | PLATEAU 5m / 5m 対照 / 0.5m / 0.5m＋点群 | あり |
| 西舞鶴 | 625 ha | PLATEAU 5m / 0.5m | なし |
| 東舞鶴 | 1,000 ha | PLATEAU 5m / 0.5m | なし |

吉原は「微地形が効くことを期待できる典型」として選んだので、結果は**効きやすい側に偏っている**
（[6.3](./pages/limits)）。

## 1.3 分析の考え方

### なぜ 5m 地形では足りないのか

PLATEAU の地形は**約 5m 間隔の地形データ**で、路地や護岸などの細かな起伏を表しにくい。
建物も **LOD1**（詳細度 1）のため、箱形の簡略モデルである。
「どの道路・どの建物が浸かるか」を 1 件ずつ問うには、地形が粗い。

### データの役割分担

3D で重ねて見せるのではなく、**データごとに役割を分けて突き合わせる**。

| データ | 役割（何をする） |
|---|---|
| **PLATEAU**（建物・道路） | どの建物・どの道路かを**識別する**（ID・用途・構造） |
| **京都府 DEM・地上点群** | その場所の**高さを測る**（地表面の標高） |
| **本プロジェクトの解析** | 高さと潮位から**浸水判定を計算する**（地物ごとの地盤高・浸水開始潮位・浸水深と、地形データを変えたときの判定の変化） |

PLATEAU は書き換えず、地物 ID に解析結果を**外付け**する（PLATEAU が更新されても ID で貼り直せる）。

## 1.4 使用データ

| データ | 使い方 |
|---|---|
| **PLATEAU 地形モデル LOD1**（約 5m 間隔の TIN） | 比較の出発点。viewer では「PLATEAU 5m」 |
| **京都府 数値標高モデル（DEM）0.5m**（航空レーザ実測） | 高解像度の実測地形。viewer では「0.5m」 |
| ― 上を 5m に平均集約した対照 | 「データ源の違い」と「解像度の違い」を切り分けるための比較用。viewer では「5m 対照」 |
| **地上点群**（バックパック SLAM、吉原のみ） | 下記のとおり、表示と一部の補正に使う。viewer では「0.5m＋点群」 |
| **気象庁 推算潮位**（舞鶴） | 潮位スライダの参照水位、潮位の記録の再生、潮位表基準面 → T.P. の換算 |
| **気象庁 観測潮位**（1998 既往最高／2026 速報） | 実測 2 事象・既往最高潮位との突き合わせ |
| **国土数値情報 鉄道（N02）** | PLATEAU に鉄道が無いため別途取得。市が示した表示範囲の基準線 |
| **e-Stat 統計 GIS 境界・国勢調査小地域** | 小地域ごとの浸水建物集計、任意地点圏域の人口集計 |

各データの規模・出典は [付録 D](./pages/sources)。

::: info 点群の役割と限界
地上点群は**表示にも使い、一部は 0.5m DEM の補正にも使う**。ただし、
バックパック SLAM は歩いた線に沿った帯しか取れず、**取得範囲が狭い**（AOI の 7.9 %）。
**全域を点群で置き換えるものではない**（[4.2](./pages/results)）。
:::
