# 舞鶴市 高潮シミュレーション — 結果と示唆

舞鶴市から示された課題（`舞鶴市資料.pptx` スライド 2〜3、都市計画課 2026-08）に沿って、
高潮の浸水判定が **地形データを変えるとどこで変わるか** を地物単位で調べた。
このレポートはその結果と、市への示唆をまとめたもの。

- 公開 viewer: **<https://iwagaki-viewer.tonbo.workers.dev>**
- 解析リポジトリ: <https://github.com/masatomoty/iwagaki>
- 内部の作業ノート（`[実測]`/`[未確認]` タグ付き、詳細版）はリポジトリの `docs/` にある。
  このレポートはそこから報告用に組み直したもので、数字は `docs/results.md` と一致する。

::: tip このレポートの読み方
`[実測]` = このリポジトリで実際に計算・計測した値。`[未確認]` = 外部の確定情報待ち。
`[既知]` = 公表資料・先行研究による。数字はすべて出典をたどれるようにしてある。
:::

## 元のお題との対応

| pptx で示された課題 / やりたいこと | このレポートでの扱い |
|---|---|
| 3D都市モデルの地形が **LOD1**（5mメッシュ）で、高潮の詳細な浸水範囲がわからない | [① 場所が変わる](./pages/results-spatial) / [② 主因はデータソース](./pages/results-source) |
| 将来の**海面上昇**で浸水範囲がどれだけ広がるか把握したい | [④ 海面上昇でどこまで広がるか](./pages/results-sealevel) |
| ① 任意の潮位を設定 → 3D都市モデルに海面を可視化 | [viewer](./pages/viewer)（潮位スライダ） |
| ② 時刻歴の潮位データ → 海面変化を可視化 | [viewer](./pages/viewer)（潮位再生） |
| ③ 3D都市モデルの地形だけでなく**点群データ**との重ね合わせ | [③ 点群の位置づけ](./pages/results-pointcloud) / [viewer](./pages/viewer)（点群表示） |
| （提供）3D都市モデル（市街化区域）・吉原地区の点群（LAS） | [手法と前提](./pages/method) に取り込み結果 |

さらに、解析中に舞鶴市から**実際の高潮被害記録**を受領できたので、
モデルと実測の突き合わせも行った（[⑤](./pages/results-validation)）。
お題の範囲外だが市の要望で足した機能（交通規制の可視化、小地域集計ほか）は
[お題の外で足したもの](./pages/extras) に一覧。

## 対象範囲

| 範囲 | 面積 | 地形条件 | 点群 |
|---|---:|---|---|
| **吉原**（当初 AOI） | 100 ha | PLATEAU 5m / 0.5m DEM / 5m対照 / 点群融合 の 4 条件 | あり |
| 西舞鶴 | 625 ha | PLATEAU 5m / 0.5m DEM | なし |
| 東舞鶴 | 1,000 ha | PLATEAU 5m / 0.5m DEM | なし |

吉原が主対象。西・東舞鶴は市の要望で面的表示用に後から足した独立範囲で、
「吉原 1 km 四方の特殊事情ではない」ことの裏付けに使う。
