# 1. 背景と目的

## 1.1 課題

舞鶴市（都市計画課）から 2026 年 8 月に示された課題を起点とする。

- 3D 都市モデル（PLATEAU）の地形データは **LOD1**（5m メッシュ）のため、高潮による
  詳細な浸水範囲を把握できない。
- 将来の**海面上昇**を見込むと、浸水範囲がどの程度広がるかを把握する必要がある。
- あわせて、任意の潮位・時刻歴の潮位で海面を可視化し、**点群データ**とも重ねたい。

舞鶴市には既往最高潮位 T.P.+0.93 m（1998 年 9 月・台風 7 号）の記録があり、
令和 8 年 2 月には京都府により高潮浸水想定区域（水防法第 14 条の 3）に指定されている。
一方で、5m メッシュの地形は路地や護岸の細かい起伏を均してしまうため、
「どの道路・どの建物が浸かるか」を地物単位で問うには粗い。

本プロジェクトは、**同じ潮位に対して地形データを差し替えると浸水判定がどこで変わるか**を
地物単位で調べ、その結果を市の判断に返すことを目的とする。

## 1.2 主要なデータと使い方

3D で重ねて見せるのではなく、**データごとに役割を分けて突き合わせる**。

| 役割 | データ | 担うもの |
|---|---|---|
| **地物の識別子と意味** | PLATEAU（建物・道路） | 建物・道路 1 件ごとの ID、用途・構造、道路の区間種別（橋梁/高架/トンネルの除外に使う） |
| **現況の微地形** | 京都府 0.5m DEM ／ 地上点群 | 地表面の標高。ここから地物ごとの地盤高を取る |
| **導かれる判定** | 本プロジェクトの解析 | 地物ごとの地盤高・浸水開始潮位・浸水深と、地形データを変えたときの判定の変化 |

PLATEAU は書き換えず、地物 ID に解析結果を**外付け**する（PLATEAU が更新されても ID で貼り直せる）。

| データ | 使い方 |
|---|---|
| **PLATEAU 地形モデル LOD1**（5m 格子相当の TIN） | 比較の出発点＝`baseline` 地形 |
| **京都府 数値標高モデル（DEM）0.5m** | 実測の高解像度地形＝`highres`。5m に平均集約した対照＝`control`（データ源と解像度の切り分けに使う） |
| **地上点群**（バックパック SLAM、吉原のみ） | 0.5m DEM に地表面を融合＝`pointcloud`。viewer の点群表示にも |
| **気象庁 推算潮位**（舞鶴） | 潮位スライダの参照水位、潮位の記録の再生、潮位表基準面 → T.P. の換算 |
| **気象庁 観測潮位**（1998 既往最高／2026 速報） | 実測 2 事象・既往最高潮位との突き合わせ |
| **国土数値情報 鉄道（N02）** | PLATEAU に鉄道が無いため別途取得。市が示した表示範囲の基準線 |
| **e-Stat 統計 GIS 境界・国勢調査小地域** | 小地域ごとの浸水建物集計、任意地点圏域の人口集計 |

各データの規模・出典は [付録 D](./pages/sources)。

## 1.3 成果物の概要

| 成果物 | 内容 |
|---|---|
| **viewer** | 潮位スライダ・潮位の記録の再生・点群表示・地形条件の比較・交通規制表示・雨量シナリオ・地域別集計。<br><https://iwagaki-viewer.tonbo.workers.dev> |
| **解析パイプライン** | 4 つの地形条件 × 3 範囲（吉原・西舞鶴・東舞鶴）の浸水判定。PLATEAU の地物 ID に地盤高・浸水深・判定の変化を外付け。<https://github.com/masatomoty/iwagaki> |
| **現場運用向けの出力** | 次の高潮時の巡回対象リスト、小地域ごとの浸水建物集計（CSV / GeoJSON、市へ個別提供） |
| **本レポート** | 結果と提言のまとめ |
