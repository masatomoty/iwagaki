# viewer の使い方

公開先: **<https://iwagaki-viewer.tonbo.workers.dev>**

お題の ① 任意の潮位 → 海面可視化 / ② 時刻歴の潮位 → 海面変化 / ③ 点群との重ね合わせ は
すべて viewer で確認できる。設計は `docs/web_design.md`、配信性能の実測は `docs/web_results.md`。

## できること

| 操作 | 内容 |
|---|---|
| **対象範囲** | 吉原（100 ha・4 条件・点群あり）／西舞鶴（625 ha）／東舞鶴（1,000 ha）。広い 2 つは 0.5m DEM と PLATEAU 5m だけ |
| **地形データ** | その範囲が配信している条件を切り替える。並びは作られ方の順（源を替える → 解像度を上げる → 観測を足す） |
| **判定差** | 選んだ条件に至る 1 段の差を面で塗る。`5m 対照` ならデータ源だけの差 |
| **潮位**（お題 ①） | 0.00〜3.00 m T.P. を 0.05 m 刻みで動かす。**サーバ往復も再計算も起きない**（[h_conn 設計](./method)） |
| **潮位再生**（お題 ②） | 気象庁の毎時推算潮位を時系列で流し、海面の高さが動く |
| **浸水の決め方** | 既定は単純モデル（潮位 − 地盤高）。「海からつながる」で連結モデルに戻る。切り替えは uniform 1 個で配信物は変わらない |
| **地形の色** | 浸水深 / 地盤高 / 水みち。地盤高は 0〜3 m のグラデーションで「どこの地盤が低いか」だけを出す |
| **窪地** | 連結モデルで、標高は潮位より低いが海に出ない土地を斜線で示す |
| **仮定の段階** | その土地が浸かると言うのにどこまで仮定を置いているかを 3 段で（西・東舞鶴）。下 2 段は色ではなく斜線 |
| **建物の色** | 用途 / 浸水深（床下・床上 0.50 m） |
| **道路** | 293 本。浸かると通行支障クラス（0.1 / 0.3 / 0.5 m）。交通規制モードは市の 3 段（迂回 / 徐行 / 通行止め） |
| **絞り込み** | 判定が変わる地物だけを残す |
| **地物のクリック** | その条件の地盤高・h_conn・浸水深・通行と、基準との差 |
| **断面** | 2 点クリックで測線。**4 条件を線で重ねられる唯一の場所** |
| **点群**（お題 ③） | バックパック SLAM の実測色で表示。表示専用（解析には融合地形ラスタを使う） |

## 配信の考え方

- **水位を動かしてもサーバ計算が発生しない。** `h_conn` を 1 枚焼いてタイルの α チャネルに
  入れてあり、`wet(H) = h_conn ≤ H` / `depth(H) = max(0, H − 標高)` の 2 式をシェーダで評価する。
- **モデルの切り替え・地形の色・仮定の段・窪地は、すべて既存タイルの別チャネルの読み替え**で、
  配信物は 1 バイトも増えない。
- COPC 点群だけは CDN キャッシュに乗らない（`docs/platform.md`）。
