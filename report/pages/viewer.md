# 2. viewer の操作

公開先: **<https://iwagaki-viewer.tonbo.workers.dev>**

ブラウザで開くだけで動く。インストールやログインは不要。この章は、初めて開いた方が
順に操作する流れをまとめる。表示された数字の読み方は [3. 表示の解釈](./interpretation) を参照。

## 2.0 操作の流れ

1. **対象地域を選ぶ** — 吉原 / 西舞鶴 / 東舞鶴
2. **浸水モデルを確認する** — 単純 / 海からつながる（[3.1](./interpretation)）
3. **潮位を選ぶ** — スライダ、または参照潮位
4. **建物・道路の表示を切り替える** — 浸水深 / 用途、通行支障 ほか
5. **地物をクリックして詳細を見る** — 「属性情報」タブ

必要に応じて：

6. **地形データを切り替えて差を見る**（[2.4](#_2-4-地形条件を切り替えて差を見る)）
7. **断面・潮位の記録の再生・雨量シナリオ**（[2.5](#_2-5-その他の機能)）

## 2.1 最初に条件を選ぶ

開くと、条件を選ぶ画面が出る。

![起動時の条件選択](/viewer-startup.jpg)

- **浸水の決め方** — 初期の選択は「単純（潮位 − 地盤高）」。舞鶴市の現場の経験則に
  沿った見方で、初めて見るときはこれで足りる。あとから操作パネルで切り替えられる（[3.1](./interpretation)）。
- **対象地域** — 吉原（100 ha・地上点群あり）／西舞鶴（625 ha）／東舞鶴（1,000 ha）。
- **潮位** — 潮位は、標高の基準である **T.P.（東京湾平均海面）からの高さ**で示す。
  普段（平均海面）0.31 m ／ 高潮想定の基準潮位 0.69 m ／ 既往最高潮位（1998）0.93 m の 3 つ。
  初期の選択は高潮想定の基準潮位。

「この条件で見る」を押すと地図に入る。

### どの画面でどのモデルか

| 場面 | 初期設定 |
|---|---|
| 起動時の条件選択画面 | **単純モデル** |
| 条件選択後の操作パネル | 連結モデル（「海からつながる」） |
| 「次回から表示しない」を選んだ後 | 連結モデル |

条件選択画面だけ単純モデルを初期選択にしているのは、初めて見る人が
「地盤が低いのに色が付かない」で戸惑わないように、まず一番素直な見方から入ってもらうため。

::: tip 条件選択画面をもう一度出すには
「次回から表示しない」にチェックした後で戻したいときは、URL に `?intro=1` を付けて開く
（例：<https://iwagaki-viewer.tonbo.workers.dev/?intro=1>）。なお、地域・モデル・潮位は
すべて操作パネルからいつでも変更できる。
:::

## 2.2 潮位を動かす

左パネルの **「浸水条件」タブ**に潮位スライダがある。

![浸水条件タブ](/viewer-conditions.jpg)

- **スライダ** — 0.0〜2.0 m T.P. を 0.05 m 刻み。配信データは 3.0 m まであるが、
  既往最高潮位 0.93 m・高潮想定 0.69 m に対して目盛りが間延びするため 2.0 m で頭打ちにしている。
- **キー操作** — **潮位スライダをクリックしてフォーカスを当てる**と、`← →` で 0.01 m ずつ、
  `Shift ＋ ← →` で 0.05 m ずつ動かせる。矢印キーがスライダの刻み（0.05 m）より細かい
  0.01 m なのは、[4.1](./results) のとおり**この水位帯では数 cm で浸水域が大きく変わる**ため、
  cm 単位で追い込めるようにしている。
- **参照潮位** — 平均海面・朔望平均満潮位・既往最高潮位などの一覧。押すとその値に飛ぶ。
- 潮位を動かしても**サーバとの通信も再計算も発生しない**（仕組みは [6.1](./limits)）。

### 潮位の記録の再生

同じタブの下方に「潮位の記録を再生」がある（お題の「時刻歴の潮位データを入力すると
海面変化が可視化される」に対応。[付録 A](./appendix-correspondence)）。

![潮位の記録を再生](/viewer-tide-playback.jpg)

::: warning これは時間発展シミュレーションではない
水の流れを時間で追うシミュレーションではない。**各時刻の潮位を使って、浸水範囲を
1 枚ずつ静水位で解いて並べたもの**である。越流の速さ・流量・波は含まない。
:::

- 再生できる曲線は 3 種 — **実測の台風イベント**（1998 年など）／**天文潮**（気象擾乱を含まない）／
  **気象庁の潮位予測**（現在〜7 日後）。
- 気象庁の予測は「⟳ 気象庁予測を更新」で取得し直せる（更新されるのは予測曲線のみ）。
- 再生の速さは 1分/秒・5分/秒・30分/秒。**その曲線の最高潮位に達すると自動で止まる**
  （表示可能な最大潮位ではなく、選んだ曲線のピーク値）。

## 2.3 どの建物・道路が浸かるかを見る

![浸水判定の表示](/viewer-overview.jpg)

- **建物の色**（「基本設定」タブ）— 初期は**浸水深（床下 / 床上）**。「建物の色」の
  プルダウンで用途別の表示に切り替えられる。
- **道路の色**（「基本設定」タブ）— 初期は「一律」（白）。「道路の色」のプルダウンで
  「通行支障（0.1 / 0.3 / 0.5 m）」または「交通規制（徐行 / 通行規制検討 / 通行止め相当）」に。
  交通規制は安全側に広く出すため、地図の建物色とは別のモデルを使う（[3.1](./interpretation)）。
- **地形の色**（左上のボタン 4 つ）— 浸水深 / 地盤高 / 水みち / 雨量（[3.3](./interpretation)）。
- **地物のクリック** — 「属性情報」タブに詳細が出る。**建物**は地盤高・浸水開始潮位・
  浸水深・基準条件との差、**道路**はこれに通行支障クラスが加わる。

![地物インスペクタ](/viewer-inspector.jpg)

::: warning 「床下 / 床上」は表示上の分類
ここでの床下／床上は、**地盤面からの浸水深 0.50 m を境にした表示上の分類**であり、
実際の床面の高さや家屋被害を表すものではない（[3.4](./interpretation)）。
:::

## 2.4 地形条件を切り替えて差を見る

「基本設定」タブの **「比較表示」**で、地図の塗り方を「浸水するか」から
「地形データや排水モデルで判定がどう割れるか」に変える。

![地形条件の判定差](/viewer-diff.jpg)

- **地形条件の判定差** — いま選んでいる地形データと基準（PLATEAU 5m）で、浸水判定が
  割れる場所を塗る。
  - 赤 = 0.5m でのみ浸水、黄 = PLATEAU 5m でのみ浸水、紫 = どちらでも浸水、
    **色が付かない = どちらでも浸水しない**。
- **排水モデルの差** / **仮定の段階** — 西舞鶴・東舞鶴のみ（[3.2](./interpretation)）。
- **地形データ** のプルダウンで条件そのものを切り替えられる。並びは作られ方の順
  （データ源を替える → 解像度を上げる → 地上観測を足す）。

::: tip 比較結果は潮位・モデルで変わる
判定差は**いまの潮位・浸水モデルに対する比較**である。潮位スライダを動かすと色も変わる。
:::

## 2.5 その他の機能

| 機能 | 内容 | どこから |
|---|---|---|
| **断面** | 2 点をクリックして測線を引くと、4 つの地形条件の地表面を線で重ねて比較できる | ツールバー「測線を引く」 |
| **点群** | 吉原のバックパック SLAM 点群を実測色で表示（表示専用。お題の「点群との重ね合わせ」に対応） | 「基本設定」タブ「点群」 |
| **雨量シナリオ** | 降雨時の**簡易な内水リスク**。潮位とは独立。**これは浸水深ではない**（[3.3](./interpretation)） | 「地形の色」→「雨量」＋「浸水条件」タブ |
| **地域別ランキング** | 浸水建物の多い小地域の順位表（西・東舞鶴）。**モデル由来の推計値であり公式統計ではない** | 「潮位の記録を再生」の下 |
| **徒歩圏（等時線）** | 事前生成した徒歩圏を面で表示。起点は一覧から選ぶ（[付録 E](./other-cities)） | 「基本設定」タブ「徒歩圏（等時線）」 |
| **JR 線路** | PLATEAU に鉄道が無いため国土数値情報から別途重ねる。市が示した表示範囲の基準線 | 「基本設定」タブ |

![断面（4 条件を重ねる）](/viewer-section.jpg)

![点群表示（歩いた線に沿った帯）](/viewer-pointcloud.jpg)

::: info 色の意味について
赤・黄・紫などの色分けは、凡例にラベルを併記している。地形の色モードによって
凡例の内容が切り替わる（[3.3](./interpretation)、[3.2](./interpretation)）。
:::
