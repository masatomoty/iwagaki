# 2. viewer の操作

公開先: **<https://iwagaki-viewer.tonbo.workers.dev>**

ブラウザで開くだけで動く。インストールやログインは不要。この章は、初めて開いた方が
順に操作する流れをまとめる。表示された数字の読み方は [3. 表示の解釈](./interpretation) を参照。

## 2.1 対象範囲の選択

画面上部で対象範囲を切り替える。

| 範囲 | 面積 | 地形データ | 点群 |
|---|---:|---|---|
| **吉原** | 100 ha | 4 条件（PLATEAU 5m / 5m 対照 / 0.5m / 0.5m＋点群） | あり |
| **西舞鶴** | 625 ha | 2 条件（PLATEAU 5m / 0.5m） | なし |
| **東舞鶴** | 1,000 ha | 2 条件（PLATEAU 5m / 0.5m） | なし |

吉原が当初からの対象。西・東舞鶴は市の要望で面的表示用に後から加えた範囲で、
JR 駅周辺を含む。広い 2 範囲は 0.5m DEM と PLATEAU 5m の 2 条件のみ。

## 2.2 潮位の設定と再生

- **潮位スライダ** — 0.00〜3.00 m T.P. を 0.05 m 刻みで動かす。海面の高さと、
  建物・道路・地形の浸水表示がその場で追従する。**サーバとの通信も再計算も発生しない**
  （仕組みは [3.1](./interpretation) と [6.1](./limits)）。
- **潮位再生** — 気象庁の推算潮位（舞鶴、毎時）を時系列で流し、海面の上下を再現する。
  お題の「時刻歴の潮位データを入力すると海面変化が可視化される」に対応。
- 基準となる潮位（平均水面・朔望平均満潮位・既往最高潮位など）はスライダ上に目盛りで示す。

![潮位再生](/web-viewer-record-high-tide.png)

## 2.3 浸水判定の表示

- **建物** — 用途で塗るか、浸水深（床下 / 床上、境は地盤面から 0.50 m）で塗るかを選ぶ。
- **道路** — PLATEAU の道路 293 本（吉原）。浸かると通行支障クラス（0.1 / 0.3 / 0.5 m）で色分け。
- **地形の色** — 浸水深 / 地盤高 / 水みち を切り替える。地盤高は「どこの地盤が低いか」だけを
  グラデーションで示し、現在の潮位の等高線を白い線で重ねる。
- **地物のクリック** — その地物の地盤高・浸水開始潮位・浸水深・通行の可否と、基準条件との差を表示。
- **絞り込み** — 判定が条件によって変わる地物だけを残す。

![地物インスペクタ](/web-viewer-inspector.png)

## 2.4 地形条件の切り替えと差分表示

- **地形データ** を切り替えると、その条件での浸水判定に変わる。並びは作られ方の順
  （データ源を替える → 解像度を上げる → 地上観測を足す）。
- **差分表示** — 選んだ条件に至る 1 段の差を面で塗る。赤 = 新たに浸水、黄 = 浸水しなくなる。
  「5m 対照」を選べば**データ源だけ**の差、「0.5m」を選べばそこに解像度の差が乗る。

![判定差 H=1.0m](/web-viewer-diff-H1.0.png)

## 2.5 その他の機能

| 機能 | 内容 |
|---|---|
| **交通規制** | 道路が浸かったときの通行支障を市の 3 段（迂回 / 徐行 / 通行止め）で塗る。安全側に広く出すため、地図の建物色とは意図的に別のモデルを使う（[3.1](./interpretation)） |
| **地域別ランキング** | 潮位再生パネルの下に、浸水建物の多い小地域の順位表を表示（西・東舞鶴） |
| **断面** | 地図上で 2 点をクリックして測線を引く。4 つの地形条件を線で重ねて比較できる |
| **点群** | 吉原のバックパック SLAM 点群を実測色で表示（表示専用。浸水解析には融合した地形を使う） |
| **水みち・窪地** | 一様降雨時に地表流が集まる筋と、海に通じない窪地の越流点。潮位とは独立した別表示（[3.3](./interpretation)） |
