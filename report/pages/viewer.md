# 2. viewer の操作

公開先: **<https://iwagaki-viewer.tonbo.workers.dev>**

ブラウザで開くだけで動く。インストールやログインは不要。この章は、初めて開いた方が
順に操作する流れをまとめる。表示された数字の読み方は [3. 表示の解釈](./interpretation) を参照。

## 2.1 最初に条件を選ぶ

開くと、条件を選ぶ画面が出る。

![起動時の条件選択](/viewer-startup.jpg)

- **浸水の決め方** — 既定の選択は「単純（潮位 − 地盤高）」。舞鶴市の現場の経験則に
  沿った見方で、初めて見るときはこれで足りる。あとから操作パネルで切り替えられる
  （[3.1](./interpretation)）。
- **対象地域** — 吉原（100 ha・地上点群あり）／西舞鶴（625 ha）／東舞鶴（1,000 ha）。
- **潮位** — 普段（平均海面）0.31 m ／ 高潮想定の基準潮位 0.69 m ／ 既往最高潮位（1998）0.93 m。
  既定の選択は高潮想定の基準潮位。

「この条件で見る」を押すと地図に入る。「次回から表示しない」にチェックすると次回から
この画面は出ず、パネルの既定（浸水の決め方は「海からつながる」）で始まる。

## 2.2 潮位を動かす

左パネルの **「浸水条件」タブ**に潮位スライダがある。

![浸水条件タブ](/viewer-conditions.jpg)

- **スライダ** — 0.0〜2.0 m T.P. を 0.05 m 刻み。配信データは 3.0 m まであるが、
  既往最高潮位 0.93 m・高潮想定 0.69 m に対して目盛りが間延びするため 2.0 m で頭打ちにしている。
- **キー操作** — 地図にフォーカスがあれば ← → で 0.01 m ずつ、Shift ＋ ← → で 0.05 m ずつ動く。
- **参照潮位** — 平均海面・朔望平均満潮位・既往最高潮位などの一覧。押すとその値に飛ぶ。
- 潮位を動かしても**サーバとの通信も再計算も発生しない**（仕組みは [6.1](./limits)）。

### 潮位の記録を再生（お題②）

同じタブの下方に「潮位の記録を再生」がある。

![潮位の記録を再生](/viewer-tide-playback.jpg)

- 再生できる曲線は 3 種 — **実測の台風イベント**（1998 年など）／**天文潮**（気象擾乱を含まない）／
  **気象庁の潮位予測**（現在〜7 日後）。
- 気象庁の予測は「⟳ 気象庁予測を更新」で取得し直せる（更新されるのは予測曲線のみ）。
- 再生の速さは 1分/秒・5分/秒・30分/秒。最高潮位で自動で止まる。
- モデルの時間発展ではなく、各時刻を静水位で解いて並べたもの。

## 2.3 どの建物・道路が浸かるかを見る

![浸水判定の表示](/viewer-overview.jpg)

- **建物の色**（「基本設定」タブ）— 既定は**浸水深（床下 / 床上、境は地盤面から 0.50 m）**。
  用途で塗る表示にも切り替えられる。
- **道路の色** — 既定は「一律」（白）。「通行支障（0.1 / 0.3 / 0.5 m）」または
  「交通規制（徐行 / 通行規制検討 / 通行止め相当）」に切り替えられる。交通規制は安全側に
  広く出すため、地図の建物色とは別のモデルを使う（[3.1](./interpretation)）。
- **地形の色** — 浸水深 / 地盤高 / 水みち / 雨量 の 4 つ（[3.3](./interpretation)）。
- **地物のクリック** — 「属性情報」タブに、その地物の地盤高・浸水開始潮位・浸水深・
  基準条件との差が出る。

![地物インスペクタ](/viewer-inspector.jpg)

## 2.4 地形条件を切り替えて差を見る

「基本設定」タブの **「比較表示」**で、地図の塗り方を「浸水するか」から
「地形データや排水モデルで判定がどう割れるか」に変える。

![地形条件の判定差](/viewer-diff.jpg)

- **地形条件の判定差** — いま見ている地形データと基準（PLATEAU 5m）で、浸水判定が
  割れる場所を塗る（赤 = 0.5m でのみ浸水、黄 = PLATEAU 5m でのみ浸水、紫 = どちらも浸水）。
- **排水モデルの差** / **仮定の段階** — 西舞鶴・東舞鶴のみ（[3.2](./interpretation)）。
- **地形データ** のプルダウンで条件そのものを切り替えられる。並びは作られ方の順
  （データ源を替える → 解像度を上げる → 地上観測を足す）。

## 2.5 その他の機能

| 機能 | 内容 |
|---|---|
| **断面** | ツールバーの「測線を引く」で 2 点をクリックして測線を引く。4 つの地形条件を線で重ねて比較できる |
| **点群**（お題③） | 「基本設定」タブの「点群」で、吉原のバックパック SLAM 点群を実測色で表示（表示専用） |
| **雨量シナリオ** | 降雨時の簡易な内水リスク。潮位とは独立（[3.3](./interpretation)） |
| **地域別ランキング** | 「潮位の記録を再生」の下に、浸水建物の多い小地域の順位表（西・東舞鶴） |
| **徒歩圏（等時線）** | 事前生成した徒歩圏を面で表示。起点は一覧から選ぶ（[付録 E](./other-cities)） |
| **JR 線路** | PLATEAU に鉄道が無いため国土数値情報から別途重ねる。市が示した表示範囲の基準線 |
