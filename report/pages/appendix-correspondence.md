# 付録 A. 元の課題との対応

舞鶴市提供資料（`舞鶴市資料.pptx` スライド 2〜3、都市計画課 2026-08）で示された
課題・要望と、本レポートでの扱いの対応。

| 提供資料での記述 | 本レポートでの扱い |
|---|---|
| 3D 都市モデルの地形データは **LOD1**（5m メッシュ）のため、高潮による詳細な浸水範囲を把握できない | [4.2 地形データによる浸水範囲の変化](./results) |
| 将来的に更なる海面上昇が予測される中、浸水範囲がどの程度広がるのか把握する必要がある | [4.3 対象範囲による地盤高の差](./results) |
| 任意の潮位を設定すると、3D 都市モデルに海面が可視化される | [2.2 潮位の設定と再生](./viewer) |
| 時刻歴の潮位データを入力すると、海面変化が可視化される | [2.2 潮位の設定と再生](./viewer)（潮位再生） |
| 3D 都市モデルの地形だけでなく、点群データとの重ね合わせも可能に | [2.5 その他の機能](./viewer)（点群）／[4.2](./results)（点群の位置づけ） |
| （提供データ）3D 都市モデル（市街化区域）、G 空間情報センターより DL 可能 | [付録 D. データ出典](./sources) |
| （提供データ）点群データ（吉原地区のみ）、LAS データ | [付録 D. データ出典](./sources)。被覆と扱いは [4.2](./results) |

## 課題を起点に広がった範囲

提供資料には無いが、プロジェクトの過程で市・他自治体との協議から加わったもの。

| 追加分 | きっかけ | 扱い |
|---|---|---|
| 実際の高潮被害記録との突き合わせ | 市（危機管理・防災課／消防本部）から調査資料を受領 | [4.1](./results) |
| 次の高潮時の巡回対象リスト | 市「位置情報と合わせた記録ができていない」 | [5.3](./discussion) |
| 小地域ごとの浸水建物集計 | 市（上田氏）の要望 | [5.3](./discussion) |
| 道路冠水時の交通規制表示 | 市（建設部土木課）の方針 | [2.5](./viewer) |
| 任意地点圏域・徒歩圏の集計 | 京都市・さいたま市の要望 | [付録 E](./other-cities) |
| 地表流の集中・窪地構造 | 外部プロダクト FARR のロジック調査 | [付録 E](./other-cities) |
