# 3. 表示の解釈

viewer が出す数字を誤読しないための前提をまとめる。ここを飛ばすと、以降の
[分析結果](./results) の意味を取り違えやすい。

**まず 3 行で：**

- この viewer には、**海水による浸水の判定**と、**雨水による内水リスクの表示**がある。
- 海水の浸水判定には、**単純モデル**と**連結モデル**の 2 つ（＋その中間の仮想排水路モデル）がある。
- 雨量の表示は浸水深ではなく、**地形から見た相対的な危険度**である。

## 3.1 浸水判定モデルと既定値

### 3 つのモデル

浸水の決め方は 3 通りある（「浸水条件」タブの「シミュレーション条件」）。
**「どこまで水が届くか（到達判定）」だけが違い、「浸水深の計算」はどれも `潮位 − 地盤高` で同じ。**

| モデル | 到達判定（そのセルを浸水とみなす条件） | 位置づけ |
|---|---|---|
| **単純**（潮位-地盤高） | 地盤高が潮位より低い | 舞鶴市の現場の経験則。起動画面の初期選択 |
| **海からつながる**（連結） | 上に加えて、**海の水面から地表面をたどって到達できる** | パネルの既定。[分析結果](./results) の数字はこのモデル |
| **仮想排水路** | 連結に加えて、**仮想的な排水路の吐口からの逆流**でも到達できる | 西舞鶴・東舞鶴のみ |

**具体例。** 地盤高が潮位より低い土地でも、海との間に護岸や盛土があって地表面で
つながっていなければ、**連結モデルでは「浸水しない」、単純モデルでは「浸水する」**と判定が分かれる。
排水路の吐口があれば、そこを逆流して届く可能性を見込むのが仮想排水路モデル。

### どの画面でどのモデルか

| 場面 | 初期モデル |
|---|---|
| 初回起動時の条件選択画面 | **単純モデル** |
| 条件選択後の操作パネル | 連結モデル |
| 「次回から表示しない」を選んだ後 | 連結モデル |

初回の条件選択画面だけ単純モデルを初期選択にしているのは、**初めて見る人が
「地盤が低いのに色が付かない」で戸惑わないように**、まず一番素直な見方から入ってもらうため。
操作パネルではいつでも切り替えられる。

### なぜ単純モデルを併置しているか

もともとは連結モデルだけだった。しかし東舞鶴について市から
「0.8 m の潮位でも浸水するはずの範囲が着色されない」との指摘があり、調べた結果、
**地表面の連結だけを判定するモデルとしては、着色されない結果は整合していた**
（市街が護岸天端に囲まれた窪地。[4.4](./results)）。
ただし排水路からの逆流を考えると、**現実の浸水は過小評価している可能性がある**。
市の回答は次のとおりだった。

> 現場にいる経験則として、市内全域的に、排水路などを通じて、潮位よりも地盤高が
> 低い箇所は、その差だけ浸水している状況です。現時点では、単純に
> 「潮位ー地盤高＝浸水深」として可視化することで問題ない

連結性を補正するデータ（排水区・側溝の底高・逆流防止構造の有無）は市も整理できておらず、
かつ現に逆流が起きている。そこで、経験則に沿った**単純モデルを比較用に併置**し、
初めて開く人にはそちらを初期選択にした。**排水路の吐口高・フラップゲートの有無が
手に入ったら、精緻化するのは仮想排水路モデルの側**である。

## 3.2 到達経路の根拠（「仮定の段階」表示）

西舞鶴・東舞鶴を選び、「基本設定」タブの **「比較表示」→ 「仮定の段階」** を押すと、
ある土地を「浸かる」と言うのに**どれだけ確かな到達経路を示せるか**で塗り分ける。
**吉原ではこのボタンは出ない**（仮想排水路のデータが西・東舞鶴にしか無いため）。

**吐口** ＝ 排水路が海や水域につながる出口。潮位が上がると、ここから水が
排水路を逆流して内陸の窪地に入りうる。実際の吐口の位置・敷高は市も把握できていないため、
viewer では窪地の形から**機械的に置いた仮想の吐口**を使っている（実在施設ではない）。

| 段階 | 意味 | 表示 |
|:---:|---|---|
| **3 段**（根拠が最も強い） | 仮定なし。海から地表面をたどって到達できる | 面の色 |
| **2 段** | 仮想的な排水路の吐口を仮定すれば、逆流して到達できる | 斜線 |
| **1 段** | 地盤高が潮位より低いだけ。到達経路は示せない | 斜線 |
| 0 段 | 浸水条件を満たさない（塗らない） | — |

::: warning 段の数え方に注意
「3 段階」だが実際には **0〜3 の 4 状態**がある。**段の数が大きいほど根拠が強い**
（3 = 仮定なし、1 = 標高だけ）。ここは名前と直感が逆になりやすい。

3 段に入る場所は必ず 2 段・1 段にも入る（**3 段 ⊆ 2 段 ⊆ 1 段**）。だから
「成立した段の数」がそのまま「根拠の強さ」になる。段は確率ではないので、
段数を割った比率は出さない。下 2 段を斜線にしているのは、根拠の強さが違うものを
同じ強さで塗らないため。
:::

実際の吐口の位置・敷高が分かれば、この 2 段・1 段は確定した判定に置き換わる（[5.2](./discussion)）。

## 3.3 「地形の色」の 4 モード

| モード | 塗るもの | 潮位を使うか |
|---|---|---|
| **浸水深** | 潮位に対する浸水の深さ（と、判定差） | 使う |
| **地盤高** | どこの地盤が低いかを 0〜3 m のグラデーションで。浸水の色は出さず、いまの潮位の等高線だけ白線で重ねる | 等高線のみ |
| **水みち** | 一様な雨が降ったときに地表を流れる水が集まりやすい場所。窪地は水色。クリックでその地点の集水域を面で出す | 使わない |
| **雨量** | 降雨時の**簡易な内水リスク**（相対的な危険度） | 使わない |

### 雨量シナリオ（簡易・仮定に基づく内水リスク）

![雨量シナリオ（3 時間 129.5 mm）](/viewer-rainfall.jpg)

「浸水条件」タブで**雨量シナリオ**（舞鶴観測所の観測史上値など）と**流出率**を選ぶと、
実効雨量 ＝ 想定雨量 × 流出率 を計算し、その総量と平均降雨強度から、
地形的に水が集まりやすい場所・抜けにくい窪地を色で示す。

::: warning これは予測水深ではない
- 数値は**浸水深 [m] ではない**。
- **実際の浸水戸数や水深を予測するものではない。**
- 同じシナリオの中で、**相対的に危険な場所を探す**ための表示。
- 排水能力・下水管・側溝・ポンプは考慮していない。
:::

「集水量の対数」で塗っているのは、上流から水が集まりやすい場所を強調するため、
集水量をそのままではなく対数スケールにしているという意味。

### 窪地・水みちは判定に混ぜていない

- **この章でいう「窪地」** ＝ 標高は潮位より低いが、地表面をたどると海に出ない土地
  （潮位に依存する）。連結モデルでは斜線で示し、浸水判定には混ぜていない。
  単純モデルではここも浸水域として塗られる。
  **[付録 E](./other-cities) の地形解析でいう「窪地」（潮位に依存しない地形単独の窪地）とは定義が異なる。**
- **水みち** — 潮位とは無関係の別表示。「一様な雨・地形のみ」で、浸透・管路・
  実際の降雨分布は含まない。

## 3.4 凡例と数値の定義

| 用語 | 定義 |
|---|---|
| **T.P.** | 東京湾平均海面。標高の基準。本レポートの潮位はすべて T.P. 表記 |
| **測地成果2011 / 2024** | 標高の成果系（世代）。地形データ（PLATEAU・0.5m DEM・点群）は測地成果2011 基準、気象庁の潮位速報値は測地成果2024 基準。**例：気象庁の速報値が +0.68 m（測地成果2024）なら、解析では約 +0.87 m（測地成果2011）として扱う**（`+0.19 m` 換算）。揃えないと潮位を約 0.19 m 低く見て浸水を過小評価する |
| **地盤高** | 建物は外周 1 m リングの 10 パーセンタイル、道路は路面から取った地表面の標高。建物 footprint の内部は使わない（0.5m DEM は建物除去済みで、内部は補間値のため） |
| **床下 / 床上** | **地盤面からの浸水深による機械的な分類**（0.50 m 未満＝床下、以上＝床上）であり、**実際の床の高さや家屋被害を表すものではない**（PLATEAU LOD1 が床高を持たない）。「浸水位」の定義は市に照会中（[5.2](./discussion)） |
| **通行支障クラス** | 路面からの浸水深を、0〜0.1 / 0.1〜0.3 / 0.3〜0.5 / 0.5 m以上の4段階で表示。境界は0.1 / 0.3 / 0.5 m。交通規制区分とは別。 |
| **交通規制区分** | 浸水深が0より大きい道路を、沿道建物がなければ「徐行」、5 m以内に沿道建物があれば「通行規制検討」、浸水深0.15 m以上なら「通行止め相当」と表示。 |
| **h_conn（連結浸水開始潮位）** | そのセルに海から水が地表面をたどって到達し始める最低潮位（[6.1](./limits)）。潮位 $H$ での浸水は `h_conn ≤ H` |
| **既往最高潮位** | T.P.+0.93 m（1998-09-22、台風 7 号）。舞鶴で実際に記録された最高潮位 |
| **高潮想定の基準潮位** | T.P.+0.69 m。京都府の高潮浸水想定（910 hPa、室戸台風規模） |
