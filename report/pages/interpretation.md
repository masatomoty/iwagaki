# 3. 表示の解釈

viewer が出す数字を誤読しないための前提をまとめる。ここを飛ばすと、以降の
[分析結果](./results) の意味を取り違えやすい。

## 3.1 浸水判定モデルと既定値の考え方

浸水の決め方は 2 通りあり、viewer の**既定は単純な方**である。

| モデル | 判定式 | 使いどころ |
|---|---|---|
| **単純** | `浸水深 = max(0, 潮位 − 地盤高)` | viewer の既定。交通規制の表示 |
| **連結** | 上に加えて、海側の水面から地表面をたどって到達できること | 「海からつながる」を選んだとき |
| **仮想排水** | 連結に加えて、仮想的な排水路の吐口からの逆流を見込む | 「仮想排水路」を選んだとき（西・東舞鶴） |

### なぜ既定を単純モデルにしたか

当初は連結モデル（地表面をたどって海に到達できるセルだけを浸水とする）を既定にしていた。
しかし東舞鶴について市から「0.8 m の潮位でも浸水するはずの範囲が着色されない」との
指摘があり、調べた結果、**モデルの答えとしては正しかった**（市街が護岸天端に囲まれた
窪地になっている。[4.4](./results)）。市の回答は次のとおりだった。

> 現場にいる経験則として、市内全域的に、排水路などを通じて、潮位よりも地盤高が
> 低い箇所は、その差だけ浸水している状況です。現時点では、単純に
> 「潮位ー地盤高＝浸水深」として可視化することで問題ない

連結性を補正するデータ（排水区・側溝の底高・逆流防止構造の有無）は市も整理できておらず、
かつ現に逆流が起きている。地表面の連結だけを見て内陸を浸水なしと判定するのは
「厳密」ではなく実態から外れるため、既定を単純モデルに変えた。連結モデルは切り替えで残している。

## 3.2 根拠の強さを示す 3 段階表示

西・東舞鶴では、ある土地を「浸かる」と言うのに**どこまで仮定を置いているか**を 3 段で示す。
3 つの範囲は入れ子（狭い方が仮定が少ない）なので、成立した段の数がそのまま仮定の深さになる。

| 段 | 意味 | 表示 |
|---|---|---|
| **3 段** | 仮定なし。海から地表面をたどって到達できる | 面の色 |
| **2 段** | 仮想的な排水路の吐口があれば、逆流して到達できる | 斜線 |
| **1 段** | 地盤高が潮位より低いだけ。到達経路は示せない | 斜線 |

::: warning これは発生確率ではない
段はモデルの入れ子であって、確率でも重み付き平均でもない。段数を割った比率は出さない。
下 2 段を斜線にしているのは、根拠の強さが違うものを同じ強さで塗らないため。
:::

仮想的な吐口は**実在する施設ではなく**、窪地の形状から機械的に置いたもの。
実際の吐口の位置・敷高が分かれば、この 2 段・1 段は確定した判定に置き換わる（[5.2](./discussion)）。

## 3.3 窪地・地表流の扱い

- **窪地** — 標高は潮位より低いが、地表面をたどると海に出ない土地。連結モデルでは
  斜線で示し、**浸水判定には混ぜていない**。単純モデル（既定）ではここも浸水域として塗られる。
- **水みち（地表流の集中）** — 一様な降雨があったときに地表を流れる水がどこに集まるかを、
  地形だけから計算したもの。**潮位とは無関係の別表示**で、潮位スライダを動かしても色は変わらない。
  「一様な降雨・地形のみ」という但し書きが付く（浸透・管路・実際の降雨分布は含まない）。

## 3.4 凡例と数値の定義

| 用語 | 定義 |
|---|---|
| **T.P.** | 東京湾平均海面。標高の基準。本レポートの潮位はすべて T.P. 表記 |
| **測地成果2011 / 2024** | 標高の成果系。地形データ（PLATEAU・0.5m DEM）は測地成果2011 基準。気象庁の潮位速報値は測地成果2024 基準なので、`+0.190 m` 換算して揃えている |
| **地盤高** | 建物は外周 1 m のリングから、道路は路面から取った地表面の標高。建物 footprint の内部は使わない（0.5m DEM は建物除去済みで、内部は補間値のため） |
| **床下 / 床上** | 地盤面からの浸水深が 0.50 m 未満なら床下、以上なら床上と表示。**床の高さは考慮していない**（PLATEAU LOD1 が床高を持たないため）。「浸水位」の定義は市に照会中（[5.2](./discussion)） |
| **通行支障クラス** | 路面からの浸水深 0.1 / 0.3 / 0.5 m の 3 段階 |
| **h_conn（連結浸水開始潮位）** | そのセルが海と連結して浸水し始める最小の潮位。[6.1](./limits) |
| **既往最高潮位** | T.P.+0.93 m（1998-09-22、台風 7 号）。舞鶴で実際に記録された最高潮位 |
| **高潮想定の基準潮位** | T.P.+0.69 m。京都府の高潮浸水想定（910 hPa、室戸台風規模） |
