# 3. 表示の解釈

viewer が出す数字を誤読しないための前提をまとめる。ここを飛ばすと、以降の
[分析結果](./results) の意味を取り違えやすい。

## 3.1 浸水判定モデルと既定値

浸水の決め方は 3 通りある（「浸水条件」タブの「シミュレーション条件」）。

| モデル | 判定式 | 位置づけ |
|---|---|---|
| **単純**（潮位-地盤高） | `浸水深 = max(0, 潮位 − 地盤高)` | 舞鶴市の現場の経験則。起動画面の初期選択 |
| **海からつながる**（連結） | 上に加えて、海側の水面から地表面をたどって到達できること | パネルの既定。[分析結果](./results) の数字はこのモデル |
| **仮想排水路** | 連結に加えて、仮想的な排水路の吐口からの逆流を見込む | 西舞鶴・東舞鶴のみ |

### 2 つの「既定」がある

- **起動画面**（[2.1](./viewer)）の初期選択は **単純**。初めて見る人がまず触るのはこれ。
- 起動画面を閉じた後の**パネルの既定**は **海からつながる（連結）**。

### なぜ単純モデルを併置しているか

もともとは連結モデルだけだった。しかし東舞鶴について市から
「0.8 m の潮位でも浸水するはずの範囲が着色されない」との指摘があり、調べた結果、
**モデルの答えとしては正しかった**（市街が護岸天端に囲まれた窪地。[4.4](./results)）。
市の回答は次のとおりだった。

> 現場にいる経験則として、市内全域的に、排水路などを通じて、潮位よりも地盤高が
> 低い箇所は、その差だけ浸水している状況です。現時点では、単純に
> 「潮位ー地盤高＝浸水深」として可視化することで問題ない

連結性を補正するデータ（排水区・側溝の底高・逆流防止構造の有無）は市も整理できておらず、
かつ現に逆流が起きている。そこで、経験則に沿った**単純モデルを比較用に併置**し、
初めて開く人にはそちらを初期選択にした。**排水路の吐口高・フラップゲートの有無が
手に入ったら、精緻化するのは仮想排水路モデルの側**である。

## 3.2 根拠の強さを示す 3 段階表示

西舞鶴・東舞鶴では、「比較表示」の**「仮定の段階」**で、ある土地を「浸かる」と言うのに
**どこまで仮定を置いているか**を 3 段で示す。3 つの範囲は入れ子（狭い方が仮定が少ない）
なので、成立した段の数がそのまま仮定の深さになる。

![仮定の段階（西舞鶴、潮位 0.90 m）](/viewer-assumption.jpg)

| 段 | 意味 | 表示 |
|---|---|---|
| **3 段** | 仮定なし。海から地表面をたどって到達できる | 面の色 |
| **2 段** | 仮想的な排水路の吐口があれば、逆流して到達できる | 斜線 |
| **1 段** | 地盤高が潮位より低いだけ。到達経路は示せない | 斜線 |

::: warning これは発生確率ではない
段はモデルの入れ子（連結 ⊆ 仮想排水 ⊆ 潮位以下）であって、確率でも重み付き平均でもない。
段数を割った比率は出さない。下 2 段を斜線にしているのは、根拠の強さが違うものを
同じ強さで塗らないため。
:::

仮想的な吐口は**実在する施設ではなく**、窪地の形状から機械的に置いたもの。
実際の吐口の位置・敷高が分かれば、この 2 段・1 段は確定した判定に置き換わる（[5.2](./discussion)）。

## 3.3 「地形の色」の 4 モード

| モード | 塗るもの | 潮位を使うか |
|---|---|---|
| **浸水深** | 潮位に対する浸水の深さ（と、判定差） | 使う |
| **地盤高** | どこの地盤が低いかを 0〜3 m のグラデーションで。浸水の色は出さず、いまの潮位の等高線だけ白線で重ねる | 等高線のみ |
| **水みち** | 一様な降雨で地表流がどこに集まるか（集水セル数の対数）。窪地は水色。クリックでその地点の集水域を面で出す | 使わない |
| **雨量** | 降雨時の**簡易な内水リスク**（相対値） | 使わない |

### 雨量シナリオ（簡易・仮定に基づく内水リスク）

![雨量シナリオ（3 時間 129.5 mm）](/viewer-rainfall.jpg)

- 「浸水条件」タブで**雨量シナリオ**（舞鶴観測所の観測史上値など）と**流出率**を選ぶ。
- 実効雨量 ＝ 想定雨量 × 流出率、その総量と平均降雨強度（＝実効雨量 ÷ 継続時間）から、
  地形の集水・窪地が**どれだけ危険になりやすいか**を相対値で塗る。
- **これは浸水深 [m] ではない。相対的な危険度である。** 潮位・海水浸水とは別軸で、
  同時に扱える（潮位スライダを動かしても雨量の色は変わらない）。
- 排水区・側溝・暗渠・排水管・吐口高・フラップゲート・ポンプ能力は揃っていないため、
  下水管網を含む本格的な内水氾濫解析ではない。

### 窪地・水みちは判定に混ぜていない

- **窪地** — 標高は潮位より低いが、地表面をたどると海に出ない土地。連結モデルでは
  斜線で示し、浸水判定には混ぜていない。単純モデルではここも浸水域として塗られる。
- **水みち** — 潮位とは無関係の別表示。「一様な降雨・地形のみ」で、浸透・管路・
  実際の降雨分布は含まない。

## 3.4 凡例と数値の定義

| 用語 | 定義 |
|---|---|
| **T.P.** | 東京湾平均海面。標高の基準。本レポートの潮位はすべて T.P. 表記 |
| **測地成果2011 / 2024** | 標高の成果系。地形データ（PLATEAU・0.5m DEM・点群）は測地成果2011 基準。気象庁の潮位速報値は測地成果2024 基準なので、`+0.190 m` 換算して揃えている |
| **地盤高** | 建物は外周 1 m リングの 10 パーセンタイル、道路は路面から取った地表面の標高。建物 footprint の内部は使わない（0.5m DEM は建物除去済みで、内部は補間値のため） |
| **床下 / 床上** | 地盤面からの浸水深が 0.50 m 未満なら床下、以上なら床上と表示。**床の高さは考慮していない**（PLATEAU LOD1 が床高を持たない）。「浸水位」の定義は市に照会中（[5.2](./discussion)） |
| **通行支障クラス** | 路面からの浸水深 0.1 / 0.3 / 0.5 m の 3 段階 |
| **h_conn（連結浸水開始潮位）** | そのセルが海と連結して浸水し始める最小の潮位。[6.1](./limits) |
| **既往最高潮位** | T.P.+0.93 m（1998-09-22、台風 7 号）。舞鶴で実際に記録された最高潮位 |
| **高潮想定の基準潮位** | T.P.+0.69 m。京都府の高潮浸水想定（910 hPa、室戸台風規模） |
