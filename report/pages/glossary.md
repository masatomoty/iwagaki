# 付録 C. 用語

| 用語 | 定義 |
|---|---|
| **T.P.**（東京湾平均海面） | 標高の基準面。本レポートの潮位・地盤高はすべて T.P. 表記。 |
| **測地成果2011 / 2024** | 標高の成果系。地形データ（PLATEAU・0.5m DEM・点群）は測地成果2011 基準。気象庁の潮位速報値は測地成果2024 基準で、`+0.190 m` 換算して揃えている。揃えないと潮位を約 0.19 m 低く見て浸水を過小評価する。 |
| **AOI**（Area of Interest） | 解析対象範囲。主対象は吉原の 1 km 四方（100 ha）。 |
| **PLATEAU** | 国土交通省の 3D 都市モデル整備事業。建物・道路・地形（TIN）などを CityGML で提供。舞鶴市域は 2025 年度版。 |
| **LOD1** | Level of Detail 1。建物は箱形、地形は 5m 格子相当。 |
| **TIN**（不整三角網） | 三角形の集まりで地表面を表す形式。PLATEAU の地形モデルの形式。実測では頂点間隔 5.0 m。 |
| **0.5m DEM** | 京都府「数値標高モデル」。航空レーザ測量（2019〜2023）による 0.5 m 格子の地表面標高。 |
| **点群 / バックパック SLAM** | 人が背負って歩きながら測る 3D 点群。線に沿った帯状にしか取れない。舞鶴・吉原で 2026-07 に取得。 |
| **COPC**（Cloud Optimized Point Cloud） | 必要な範囲だけを取り出せる点群フォーマット。viewer の点群表示に使用。 |
| **地盤高** | 地物直下の地表面標高。建物は外周 1 m リングの 10 パーセンタイル、道路は路面から取る。 |
| **h_conn（連結浸水開始潮位）** | そのセルが海と連結して浸水し始める最小の潮位。1 度計算しておけば任意の潮位の判定が定数時間で決まる（[6.1](./limits)）。 |
| **seed（開放水面）** | 浸水計算の起点となる、常に潮位面にある海側の水域。 |
| **単純モデル** | `浸水深 = max(0, 潮位 − 地盤高)`。舞鶴市の経験則に沿った見方で、起動画面の初期選択（[3.1](./interpretation)）。 |
| **連結モデル** | 単純モデルに加えて、海から地表面をたどって到達できることを要求する。パネルの既定で、[分析結果](./results) の数字はこのモデル。 |
| **仮想排水路モデル（S2）** | 連結モデルに、窪地の形状から機械的に置いた仮想的な吐口からの逆流を加えたもの。吐口は実在施設ではない。 |
| **段（3 段 / 2 段 / 1 段）** | ある土地を「浸かる」と言うのにどこまで仮定を置いているかの区分（[3.2](./interpretation)）。 |
| **窪地** | 標高は潮位より低いが、地表面をたどると海に出ない土地。 |
| **水みち（地表流の集中 / flow accumulation）** | 一様な降雨時に地表を流れる水が集まる筋。潮位とは独立。 |
| **雨量シナリオ / 内水リスク** | 想定雨量と流出率から、地形の集水・窪地が降雨時にどれだけ危険になりやすいかを塗る相対値。浸水深ではない。潮位とは独立（[3.3](./interpretation)）。 |
| **流出率（C）** | 降った雨のうち地表を流れ出る割合。合理式の C 相当で、地表被覆から機械的に置いた仮定値。 |
| **床下 / 床上** | 地盤面からの浸水深が 0.50 m 未満 / 以上。床の高さは考慮していない。 |
| **通行支障クラス** | 路面からの浸水深 0.1 / 0.3 / 0.5 m の 3 段階。 |
| **既往最高潮位** | T.P.+0.93 m（1998-09-22、台風 7 号）。舞鶴で実際に記録された最高潮位。viewer の参照潮位では「既往最高」。 |
| **高潮想定の基準潮位** | T.P.+0.69 m。京都府の高潮浸水想定（910 hPa、室戸台風規模）の基準潮位。viewer の参照潮位では「高潮想定」。 |
| **朔望平均満潮位(公表)** | T.P.+0.545 m。京都府の高潮浸水想定資料に載る公表値。viewer の参照潮位名。 |
| **H.W.L.(近似)** | T.P.+0.63 m。viewer の参照潮位名。朔望平均満潮位を本リポジトリが気象庁の毎時潮位から近似したもので、公表値 T.P.+0.545 m とは別。 |
| **天文潮最高** | T.P.+0.674 m。2026 年の天文潮（気象擾乱を含まない）の最高値。viewer の参照潮位名。 |
